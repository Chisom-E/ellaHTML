CSS Colors & Backgrounds

The rgb() function defines colors using values from 0 to 255 for Red, Green, and Blue

RGBA allows colors to be transparent using the alpha channel(values are between 0 and 1). RGBA is simply RGB with transparency.

Hex codes use a # followed by six characters (numbers 0-9 and letters A-F). Its syntax is #RRGGBB or #RGB(shortcut form)

HSL is another way to define colors based on Hue (0-360), Saturation(%), and lightness(%). Its syntax is: hsl(Hue, Saturation, Lightness).

HSLA is similar to HSL but includes an alpha value for transparency
