CSS Transitions

A transition allows a CSS property change over a duration, instead of instantly.

CSS Transformations allows us to modify the shape, size, and position of an element without affecting the normal document flow.

Types of CSS Transformations include:

  • translate
  • rotate
  • scale
  • skew

Translate: The translate function moves an element from its original position without affecting the normal document flow.

Rotate:The rotate ()function rotates an element by a specific angle.

Scale:The scale() function increases or decreases the size of an element.

Skew:The skew() function distorts an element by tilting it along the X or Y axis. Tilting simply means slanting it.
