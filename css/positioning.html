CSS Positioning

Static Positioning: By default, all elements are positioned statically. This means they appear in the normal document flow.

Relative Positioning: An element positioned relatively stays in the normal flow but can be shifted using top, right, bottom, or left.

Absolute PositioningAn element positioned absolutely is removed from the normal flow. It positions itself relative to the nearest positioned ancestor (which is not static).

On Absolute Positioning

Fixed Positioning: A fixed element stays in the same position when scrolling

Sticky Positioning:A sticky element acts like relative until a certain scroll position is reached, then it behaves like fixed.
