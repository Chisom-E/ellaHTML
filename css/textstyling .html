Text Styling

Font Properties: Font Properties define how text appears on a webpage. The main font properties include; font family, font size, font weight, and font style.

The font-family property allows you to specify the font type for text.

Font size controls the text size.

Text Alignment:

The text align property defines how text is alignedwithin an element.
